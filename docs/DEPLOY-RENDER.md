# Запуск на Render — пошагово для новичка

Схема: код лежит на **GitHub**, **Render** собирает и запускает сайт, база данных — бесплатный **Neon**. Сервер настраивать не нужно, HTTPS и адрес `https://…onrender.com` Render выдаёт сам. Время — около 40 минут.

## Важно знать заранее

Бесплатный сервис Render **засыпает после 15 минут без посетителей**. Первое открытие после сна занимает 30–60 секунд. Пока сервис спит, он не ищет платежи в фоне. Если покупатель платит на странице оплаты, всё работает. Чтобы сервис не засыпал, в шаге 8 настраивается бесплатный «будильник».

Для курсового проекта и тестов этого достаточно. Для настоящих денег нужен платный тариф Render (Starter) или постоянно работающий сервер.

## Шаг 0. Что подготовить

- Архив `cryptopay.zip` (из чата).
- Email.
- Браузер Chrome.

Всё, что получаете по ходу (ссылки, ключи, пароли), записывайте в файл `cryptopay-заметки.txt`.

## Шаг 1. Распаковать проект

1. Откройте «Загрузки», нажмите правой кнопкой на `cryptopay.zip` → **Извлечь все…** → **Извлечь**.
2. Должна появиться папка `cryptopay`, а в ней `server`, `web`, `docs`, `Dockerfile`, `render.yaml`.

✅ Проверка: файлы `Dockerfile` и `render.yaml` лежат прямо в папке `cryptopay`, а не во вложенной.

> Если появилась папка `cryptopay\cryptopay`, дальше используйте **внутреннюю**.

## Шаг 2. Загрузить проект на GitHub

1. Зарегистрируйтесь на **github.com** (Sign up).
2. Скачайте и установите **GitHub Desktop**: desktop.github.com. Войдите в программе через свой аккаунт GitHub.
3. В GitHub Desktop: **File → Add local repository…** → **Choose…** → выберите папку `cryptopay`.
4. Появится надпись «This directory does not appear to be a Git repository». Нажмите ссылку **create a repository**. Имя оставьте `cryptopay` → **Create repository**.
5. Нажмите синюю кнопку **Publish repository**. Галочку **Keep this code private** можно оставить → **Publish repository**.

✅ Проверка: на github.com в вашем профиле есть репозиторий `cryptopay`, в нём видны `Dockerfile` и `render.yaml`.

## Шаг 3. База данных на Neon

1. Откройте **neon.tech** → **Sign up**. Удобнее всего войти через GitHub.
2. Создайте проект:
   - **Project name:** `cryptopay`;
   - **Region:** AWS **Europe Central (Frankfurt)**;
   - **Create**.
3. На панели проекта нажмите **Connect**.
4. **Выключите** переключатель **Connection pooling**. Это важно: с ним сервер не запустится.
5. Скопируйте строку подключения. Она выглядит так:
   `postgresql://neondb_owner:xxxx@ep-xxxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`
6. Сохраните её в заметки. **Это пароль от базы, никому не показывайте.**

✅ Проверка: в строке **нет** слова `-pooler`.

## Шаг 4. Ключ Reown (окно выбора кошельков и QR-код)

1. Откройте **dashboard.reown.com** → зарегистрируйтесь.
2. **Create project** → тип **AppKit** → имя `CryptoPay`.
3. Скопируйте **Project ID** в заметки.

Адрес сайта в Reown добавим позже, в шаге 6, когда Render его выдаст.

## Шаг 5. Запуск на Render

1. Откройте **render.com** → **Get Started** → **GitHub**. Войдите тем же аккаунтом и разрешите доступ.
2. Справа вверху нажмите **New +** → **Blueprint**.
3. Найдите в списке репозиторий `cryptopay` → **Connect**.
   Если его нет: **Configure account** → разрешите Render доступ к репозиторию `cryptopay` → вернитесь.
4. **Blueprint Name:** `cryptopay`. Render прочитает файл `render.yaml` и покажет сервис **cryptopay (Free)**.
5. Он попросит заполнить два значения:
   - **DATABASE_URL** — строка из Neon (шаг 3);
   - **REOWN_PROJECT_ID** — Project ID (шаг 4).
6. Нажмите **Deploy Blueprint** (или **Apply**).
7. Откройте сервис **cryptopay** → вкладка **Logs**. Сборка идёт 5–10 минут. Бегущий текст — это нормально.
8. В конце в логах появятся строки `api listening` и `worker started`, а статус наверху станет зелёным **Live**.

✅ Проверка:
- Наверху страницы сервиса есть адрес вида `https://cryptopay-xxxx.onrender.com`. Запишите его.
- Откройте `https://cryptopay-xxxx.onrender.com/api/health`. Должно быть `{"ok":true}`.
- Откройте `https://cryptopay-xxxx.onrender.com`. Должна появиться страница «Принимайте USDC напрямую на свой кошелёк».

> Если вы не нашли пункт Blueprint, можно создать сервис вручную. **New + → Web Service** → репозиторий `cryptopay` → **Language: Docker** → **Instance type: Free**. В блоке **Environment Variables** добавьте:
> - `DATABASE_URL`;
> - `REOWN_PROJECT_ID`;
> - `CHAINS` = `84532,11155111`;
> - `ALLOW_REGISTRATION` = `true`.
>
> Затем нажмите **Deploy Web Service**.

## Шаг 6. Разрешить домен в Reown

1. Вернитесь в dashboard.reown.com → ваш проект.
2. Найдите раздел **Domain** (или **Allowlist**) и добавьте адрес `https://cryptopay-xxxx.onrender.com`.

Без этого окно кошельков может не показывать QR-код и мобильные кошельки.

## Шаг 7. Кошелёк и создание магазина

### 7.1. MetaMask

1. Установите расширение с **metamask.io/download**.
2. **Create a new wallet** → придумайте пароль.
3. Запишите **12 слов секретной фразы на бумаге**. Никому их не показывайте и не вводите на сайтах.
4. **Account 1** с адресом `0x…` будет кошельком **магазина**.

### 7.2. Магазин

1. На вашем сайте введите название магазина.
2. Нажмите **«Взять адрес из кошелька»** → подтвердите в MetaMask.
3. Нажмите **«Открыть магазин»**.
4. Сохраните **API-ключ** (`cpk_…`) и **секрет подписи** (`whsec_…`). Их показывают **один раз**.
5. Нажмите «Я сохранил ключ, перейти к счетам».

### 7.3. Закрыть регистрацию для посторонних

1. Render → сервис **cryptopay** → **Environment**.
2. У `ALLOW_REGISTRATION` нажмите **Edit** → значение `false` → **Save, rebuild, and deploy** (или **Save changes**).
3. Подождите, пока статус снова станет **Live**.

✅ Проверка: на главной странице осталась только вкладка «Войти по ключу».

## Шаг 8. «Будильник», чтобы сервис не засыпал

1. Откройте **uptimerobot.com** → **Register for FREE**.
2. **+ New monitor**:
   - **Monitor Type:** HTTP(s);
   - **URL:** `https://cryptopay-xxxx.onrender.com/api/health`;
   - **Monitoring Interval:** 5 minutes;
   - **Create Monitor**.

✅ Проверка: через несколько минут монитор зелёный (**Up**).

## Шаг 9. Тестовая оплата (бесплатные тестовые деньги)

1. **Покупатель.** В MetaMask нажмите **Account 1** → **Add account**. Появится **Account 2**, скопируйте его адрес.
2. **Тестовые сети.** В выборе сети включите **Show test networks**.
3. **ETH на комиссию.** Найдите в Google «Base Sepolia faucet» (например, кран Coinbase Developer Platform) и получите немного ETH на адрес **Account 2**.
4. **Тестовые USDC.** На **faucet.circle.com** выберите **USDC** и сеть **Base Sepolia**, вставьте адрес **Account 2** → **Send**.
5. **Счёт.** В кабинете создайте счёт на `1` USDC → **«Открыть»**.
6. **Оплата.** Переключите MetaMask на **Account 2**, затем на странице оплаты:
   - **«Подключить кошелёк»**;
   - если появится кнопка **«Переключиться на Base Sepolia»**, нажмите её;
   - **«Оплатить…»** → **Подтвердить** в MetaMask.
7. Через 10–30 секунд появится **«Оплачено»**, а в кабинете у счёта будет статус **Оплачен**.

✅ Проверка, что деньги пришли: переключите MetaMask на **Account 1** → **Import tokens** → адрес `0x036CbD53842c5426634e7929541eC2318f3dCF7e`. Появится около 1 USDC.

С телефона: откройте ссылку на оплату на компьютере → «Подключить кошелёк» → отсканируйте QR-код в Trust Wallet или MetaMask.

## Где что лежит

| Где | Что |
|---|---|
| Ваш компьютер, папка `cryptopay` | Исходники проекта. Правите здесь, затем отправляете на GitHub |
| GitHub, репозиторий `cryptopay` | Копия кода, из неё Render собирает сайт |
| Render → Environment | Все настройки (вместо файла `.env`) |
| Neon | База данных: магазины и счета |
| Бумага | 12 слов MetaMask |
| `cryptopay-заметки.txt` | Адрес сайта, строка Neon, Project ID, API-ключ |

## Как обновить сайт после изменений в коде

1. Измените файлы в папке `cryptopay` на компьютере.
2. GitHub Desktop → внизу слева напишите, что изменили → **Commit to main** → **Push origin**.
3. Render сам пересоберёт и перезапустит сайт за 5–10 минут.

## Если что-то не работает

| Что видите | Что сделать |
|---|---|
| Сборка красная (**Build failed**) | Откройте **Logs**, прокрутите до первой ошибки, пришлите мне текст |
| В логах `Invalid environment: DATABASE_URL` | Не заполнена переменная. Render → **Environment** → вставьте строку Neon |
| В логах ошибка подключения к базе или `advisory lock` | Строка Neon с пулом. Скопируйте заново с **выключенным** Connection pooling |
| Сайт открывается 30–60 секунд | Сервис спал. Это нормально; поможет шаг 8 |
| «Сервис временно недоступен» | Сервис ещё запускается или упал. Смотрите **Logs** |
| В окне кошельков нет MetaMask, Trust, Phantom или QR-кода | Проверьте `REOWN_PROJECT_ID` в Environment и адрес сайта в Reown (шаг 6) |
| Платёж не находится | Render → **Logs** → пришлите мне строки с `job failed` |
